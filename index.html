Código de Vestimenta

Queremos veros guapísimos, elegantes… y listos para darlo todo en la pista.

Así que el dress code será formal.

Para las invitadas:
Dejad los vestidos largos para la alfombra roja y evitad los tonos blancos, marfil o muy claritos (reservado para la novia).

Para los invitados:
Traje formal. Y sí, el “me pongo una camisa bonita y ya” no cuenta 😉

Solo adultos

Aunque adoramos a los más pequeños, hemos decidido que nuestra boda sea una celebración solo para adultos.

Sabemos que para muchas familias puede requerir un poco más de organización, y os agradecemos muchísimo vuestra comprensión.

Nuestra ilusión es que todos podáis relajaros, desconectar y disfrutar la fiesta al máximo con nosotros.
